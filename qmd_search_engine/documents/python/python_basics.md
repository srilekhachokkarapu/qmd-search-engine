# Introduction

Python is a high-level, interpreted programming language.
It is widely used in automation, data science,
machine learning and web development.

## Data Types

Python supports several built-in data types.

### Numeric Types

Integer represents whole numbers.
Float represents decimal numbers.
Complex represents complex numbers.

### Collection Types

List is an ordered and mutable collection.
Tuple is an ordered and immutable collection.
Set stores unique elements.
Dictionary stores key-value pairs.

## Loops

Python supports for loops and while loops.

A for loop iterates over a sequence.
A while loop executes while a condition is true.
